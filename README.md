# Color-Sort

A browser version of a wooden color-column sorting puzzle.

Players lift only the top token from a column and drop it onto another column with room. Each puzzle is complete when the four visible target columns match the card above the board.

## Features

- 40 generated levels
- Six-token column capacity for extra working space
- Legal top-token movement by click/tap or drag
- Move count for each level
- Personal best move records saved in local browser storage
- Gold level buttons when the default move record is beaten
- Static site build with no server dependency

## Run Locally

Open `index.html` in a browser, or run the static build:

```bash
npm install
npm run build
```
